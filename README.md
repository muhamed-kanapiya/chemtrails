# Небосвод

Минималистичный дашборд на русском: воздушное движение, погода, качество воздуха и учебная модель горизонтального переноса пассивной примеси. React + Vite + Leaflet, адаптивный интерфейс.

## Возможности

- Поиск городов по всему миру, быстрый выбор, сохранение последнего города и ссылка для обмена.
- Самолёты в радиусе 25–250 км: положение, позывной, регистрация, тип, высота, скорость, курс, вертикальная скорость, возраст сообщения. След наблюдений текущей сессии и пунктирное направление на две минуты.
- Справочник модели, зарегистрированного владельца, оператора и маршрута по позывному. Пропуски не заполняются догадками; текущий план полёта не подтверждается справочником.
- Погода у земли, ветер, облачность, влажность, прогноз осадков на 72 часа.
- US AQI и PM₂.₅, PM₁₀, NO₂, O₃, SO₂, CO с единицами и пояснениями шкалы.
- Условный выброс из зафиксированной точки выбранного самолёта; прогноз ветра на ближайшем уровне давления, время 0–180 минут, диффузия и период полувыведения, анимация, экспорт сценария JSON.
- Отдельный явный деморежим. Он никогда не подменяет недоступные реальные данные автоматически.

## Запуск

```sh
npm ci
npm run dev
```

В режиме разработки Vite содержит ограниченный серверный прокси `/api/flights`. Все остальные источники запрашиваются прямо из браузера. Проверки: `npm test`; сборка: `npm run build`.

## GitHub Pages и прямой эфир

GitHub Pages раздаёт статические файлы и не выполняет серверный код. Проверено 25 октября 2026: API ADSB.lol отдаёт позиции серверу, но не возвращает CORS-заголовок для стороннего браузера. Поэтому **для прямого эфира в опубликованном приложении нужен Worker**. Приложение без Worker явно сообщает об отсутствии подключения; погода, качество воздуха, поиск городов и демосимуляция работают независимо.

Подготовлен `worker/` для Cloudflare Workers. Он принимает только GET `/flights?lat=…&lon=…&radius=…`, проверяет координаты/радиус, обращается только к фиксированному ADSB.lol, кэширует успешные ответы на 15 секунд, ограничивает CORS указанными origin. Секретов в клиенте нет. Worker не имеет прав доступа к данным пользователя и не является универсальным прокси.

1. После входа в Cloudflare: `npx wrangler deploy --config worker/wrangler.toml`.
2. При переносе на другой GitHub-аккаунт изменить `ALLOWED_ORIGINS` в конфигурации Worker.
3. В GitHub → Settings → Secrets and variables → Actions → Variables добавить **публичную переменную** `VITE_FLIGHT_PROXY` с URL Worker (без `/flights`). Это URL, не токен.
4. Settings → Pages → Source: **GitHub Actions**. Запустить workflow `Deploy to GitHub Pages` или отправить коммит в `main`.

Workflow устанавливает зависимости, запускает тесты, собирает и публикует `dist`. Относительный `base: './'` поддерживает страницы репозитория. Не храните Cloudflare API token в `VITE_*`, исходниках или GitHub Variables.

## Источники и ограничения

| Данные | Источник | Обновление приложения |
| --- | --- | --- |
| Позиции самолётов | [ADSB.lol](https://www.adsb.lol/) · ODbL 1.0 | 15 с, только при открытой вкладке |
| Реестр / маршрут | [adsbdb](https://www.adsbdb.com/), PlaneBase; маршруты David J. Taylor и Jim Mason | по выбранному борту, кэш в памяти |
| Погода | [Open-Meteo](https://open-meteo.com/en/docs) · CC BY 4.0 | 15 мин |
| Приземное загрязнение | [CAMS через Open-Meteo](https://open-meteo.com/en/docs/air-quality-api) | 30 мин |
| Города | [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api), GeoNames | по запросу |
| Карта | [OpenStreetMap](https://www.openstreetmap.org/copyright) | видимые тайлы без предварительной загрузки |
| Шкала здоровья | [AirNow AQI](https://www.airnow.gov/aqi/aqi-basics/) | пояснения категорий |

При ошибках повтор выполняется не чаще одного раза в минуту. Позиции старше 60 секунд убираются; отсутствующие числа отображаются как «—». Бесплатный ADSB.lol имеет динамические лимиты (при проверке: до 500 запросов/сутки для прямого адреса); источник может ограничить длительный сеанс. Публичные API не дают SLA; перед коммерческим запуском согласуйте использование и проверьте тарифы. Маршрутная база не скачивается, не включается в репозиторий и не экспортируется.

ADS-B не видит все самолёты; назначение «коммерческий/частный» не определяется достоверно только по транспондеру. Нет обещания полной информации о каждом борте или его владельце. Барометрическая высота не равна высоте над землёй. Концентрации CAMS — модель для ячейки, не локальный анализ и не полный состав воздуха. US AQI и текущие концентрации используют разные периоды усреднения. Данные не связывают загрязнение с конкретным рейсом и не заменяют рекомендации местных служб.

## Модель переноса

Учебная двумерная гауссова порция примеси (Gaussian puff). Центр движется по геодезической в направлении **куда** дует ветер; исходное направление API — **откуда**. Постоянная скорость в м/с берётся с ближайшего доступного уровня давления по геопотенциальной высоте. Уровни: 1000, 925, 850, 700, 500, 400, 300, 250 и 200 гПа.

```text
sigma(t) = sqrt(300² + 2 K t)       t в секундах, K в м²/с
remaining(t) = 2 ^ (-t / halfLife)  одинаковые единицы времени
radius95 = 2.448 sigma
t10 = halfLife log2(10)
```

Расчёт не включает вертикальный перенос, химические реакции, рельеф, осаждение, дозу или вымывание дождём. Период полувыведения — допущение пользователя, а не установленное свойство вещества; «до 10%» не означает время безопасного воздуха. Контур 95% — доля оставшейся массы в горизонтальной модели, не граница опасности. Прогноз дождя показан отдельно.

Обычные конденсационные следы — кристаллы льда; видимый след не доказывает распыление «химтрейлов». [Пояснения EPA](https://www.epa.gov/regulations-emissions-vehicles-and-engines/Contrails). Симуляция всегда обозначена как гипотетическая.

## Идеи развития

- Локальные станции измерений с указанием расстояния и сопоставлением с моделью CAMS.
- История наблюдаемых треков с временной шкалой и воспроизведением (отдельное хранилище).
- Уведомления по выбранному борту и порогам качества воздуха.
- Сравнение нескольких метеомоделей и ансамбль сценариев переноса с диапазоном неопределённости.
- Карта авиационного шума при наличии достоверных источников и соответствующей модели.
